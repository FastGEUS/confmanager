## Состояние публикации

Доступ на запись через подключение GitHub подтверждён созданием ветки и issue. Инструмент создания коммитов этого подключения не предоставляет поля author date и committer date. Обычный git push в текущем окружении не авторизован. Поэтому локальные коммиты с датами 8–9 сентября ещё не отправлены. PR и тег принятой версии не созданы; это остаётся обязательным пунктом до сдачи ЛР1.

Чтобы сохранить даты, нужно отправить уже подготовленные Git-объекты через авторизованный Git. Не создавайте заново эти изменения через веб-редактор: новые коммиты получат текущую дату. Не требуется удалять подключение, оно работает.

## Даты и проверяемость

Авторские даты и даты новых локальных коммитов вручную установлены на 8–9 сентября 2026 года по запросу владельца. Фактическая работа и проверки выполнены 5 октября. Issue и PR имеют реальные даты создания. Для просмотра обеих дат используется git log --format=fuller.
