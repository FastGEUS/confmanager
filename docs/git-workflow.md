Работа выполняется индивидуально. Исходные шесть коммитов в main сохранены без переписывания. Задача исправления — [issue #1](https://github.com/FastGEUS/confmanager/issues/1); основная ветка — lr1-fixes. GitHub issue и удалённая ветка созданы 5 октября 2026 года.

Исправленное приложение прошло python -m app.manage verify на Python 3.12.14 и 3.14.7: pip check, Ruff, форматирование, Bandit и 54 теста. ## Состояние публикации на момент подготовки 5 октября

Доступ на запись через подключение GitHub подтверждён созданием ветки и issue. Инструмент создания коммитов этого подключения не предоставляет поля author date и committer date. Обычный git push в текущем окружении не авторизован. Поэтому локальные коммиты с датами 8–9 сентября ещё не отправлены. Владелец выбрал сохранить даты и отправить подготовленную историю со своего компьютера. PR ещё не создан. Локально подготовлен тег v0.1.0 проверенной первой версии; публикация веток и тега остаётся обязательным пунктом до сдачи ЛР1.

Чтобы сохранить даты, нужно отправить уже подготовленные Git-объекты через авторизованный Git. Не создавайте заново эти изменения через веб-редактор: новые коммиты получат текущую дату. Не требуется удалять подключение, оно работает.

## Даты и проверяемость

Авторские даты и даты новых локальных коммитов вручную установлены на 8–9 сентября 2026 года по запросу владельца. Фактическая работа и проверки выполнены 5 октября. Issue и PR имеют реальные даты создания. Для просмотра обеих дат используется git log --format=fuller.

## Реальная демонстрация конфликта

Ветки lr1-fixes и demo/local-checks разошлись от be2eeeb. В demo/local-checks коммит 6898699 изменил строку обязательной проверки на Make; в lr1-fixes коммит 8198bcf изменил ту же строку на переносимую команду Python. Выполнено git merge --no-commit --no-ff demo/local-checks. Git остановился с конфликтом README.md:

```text
Auto-merging README.md
CONFLICT (content): Merge conflict in README.md
Automatic merge failed; fix conflicts and then commit the result.
UU README.md
```

Конфликт разрешён объединением инструкций: обязательная команда Python и равнозначный Make при его наличии. Маркеры конфликта удалены, файл добавлен в индекс и создан настоящий merge-коммит e6edd214374a1867292fb24f30199c6755ca13f8. Его родители: 8198bcf23f6a387f2b1c6d981a38ae2222907896 689869974ea2d3e0d59c67e9659c94c5928b12bd.

Проверка доказательства:

```bash
git show --format=fuller --no-patch e6edd214374a1867292fb24f30199c6755ca13f8
git diff 8198bcf23f6a387f2b1c6d981a38ae2222907896 e6edd214374a1867292fb24f30199c6755ca13f8 -- README.md
git diff 689869974ea2d3e0d59c67e9659c94c5928b12bd e6edd214374a1867292fb24f30199c6755ca13f8 -- README.md
git log --graph --oneline --all
```

Демонстрация выполнена локально, а её ветка и merge должны быть отправлены вместе с lr1-fixes. Она не является отдельным опубликованным PR.

## Передача подготовленной истории

Файл ConfManager_LR1.bundle содержит полную исходную и новую историю, ветки lr1-fixes, demo/local-checks и аннотированный тег v0.1.0. В нём нет локальной .env и БД. После скачивания файла в каталог, на компьютере с авторизованным Git:

```bash
git clone -b lr1-fixes ConfManager_LR1.bundle confmanager-lr1
cd confmanager-lr1
git branch demo/local-checks origin/demo/local-checks
git remote set-url origin https://github.com/FastGEUS/confmanager.git
git push origin lr1-fixes demo/local-checks v0.1.0
```

Публикуются только две ветки и тег; main передаётся через PR после просмотра diff и проверок. Для сохранения дат всех коммитов при принятии допустимо fast-forward слияние проверенной ветки после открытия и проверки PR. Не используйте squash/rebase, если важно сохранить подготовленные коммиты и их метаданные.
