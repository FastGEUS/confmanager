# Описание API — ConfManager (ЛР1)

Базовый URL: `http://localhost:8000`

## Служебные эндпоинты

| Метод | Путь | Описание | Авторизация |
|---|---|---|---|
| GET | /health | Проверка работоспособности | нет |
| GET | /version | Текущая версия приложения | нет |
| GET | / | Веб-интерфейс (список заявок) | нет |

## Авторизация

| Метод | Путь | Описание |
|---|---|---|
| POST | /auth/login | Логин по email/паролю (form-data: username, password), возвращает JWT |

## Участники

| Метод | Путь | Описание | Авторизация |
|---|---|---|---|
| POST | /participants | Регистрация участника | нет |
| GET | /participants/{id} | Получить участника по id | нет |

Тело запроса `POST /participants`:
```json
{
  "full_name": "Иван Иванов",
  "email": "ivan@example.com",
  "organization": "МосПолитех",
  "password": "secret123"
}
```

## Заявки

| Метод | Путь | Описание | Авторизация |
|---|---|---|---|
| POST | /applications | Подать заявку на доклад | нет |
| GET | /applications | Список всех заявок | нет |
| PATCH | /applications/{id}/status | Изменить статус заявки | оргкомитет (JWT) |

Тело запроса `POST /applications`:
```json
{ "participant_id": 1, "topic": "Автоматизация CI/CD" }
```

Тело запроса `PATCH /applications/{id}/status`:
```json
{ "status": "accepted" }
```
Допустимые значения статуса: `new`, `under_review`, `accepted`, `rejected`.

## Оргвзносы

| Метод | Путь | Описание | Авторизация |
|---|---|---|---|
| POST | /fees | Создать запись об оргвзносе для заявки | оргкомитет (JWT) |
| POST | /fees/{id}/pay | Отметить оргвзнос оплаченным | оргкомитет (JWT) |

Тело запроса `POST /fees`:
```json
{ "application_id": 1, "amount": 3000 }
```

**Бизнес-правило:** `POST /fees/{id}/pay` вернёт `400 Bad Request`, если статус связанной заявки не `accepted`.

## Ошибки

Все ошибки возвращаются в формате:
```json
{ "detail": "Человекочитаемое описание ошибки" }
```
с соответствующим HTTP-кодом (400, 401, 403, 404).
